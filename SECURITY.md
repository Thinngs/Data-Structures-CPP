# Security Policy

## Supported versions

This project is currently pre-release and does not provide a stable security-support commitment. Security fixes, when required, will target the latest development branch.

## Reporting a vulnerability

Please **do not** publish vulnerability details in a public issue.

If GitHub's **Private vulnerability reporting** is enabled for this repository, use it to submit a confidential report. Otherwise, contact the maintainer privately using an available contact method on their GitHub profile.

Include a minimal reproduction, affected files or versions, and the potential impact. We will assess reports as maintenance capacity permits.
