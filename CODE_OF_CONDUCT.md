# Code of Conduct

We aim to provide a respectful, constructive environment for learning and discussing data structures.

- Be considerate and specific when giving feedback; critique code rather than people.
- Welcome beginners and explain corrections with reproducible examples when possible.
- Do not harass, discriminate against, threaten, or disclose personal information about others.
- Avoid spam and unrelated promotional content.

Maintainers may edit, hide, or remove abusive contributions and may restrict participation when necessary.

For conduct concerns, contact the repository maintainer privately through a contact method listed on their GitHub profile. Do not publish sensitive reports in a public issue.
